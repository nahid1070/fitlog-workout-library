## 📖 About The Project

**FitLog** is a workout library website designed to help users discover and organize their fitness routines. Users can explore available workouts, view detailed workout information, add exercises to their daily workout plan, and save their favorite workouts for later.

Whether you want to start a workout today or build a collection of exercises for the future, FitLog makes managing your workout library simple and convenient.

## ✨ Key Features

### 1. 🏋️ Workout Library
- Explore available workouts in a clean **3 × 4 grid layout**.
- Browse workout cards with essential information.
- Easily discover different workout options.

### 2. 🔍 Workout Details Page
- Dedicated detail page for every workout.
- View individual workout information.
- Explore workout details before adding them to your plan.

### 3. 📅 MyPlan – Workout Management
- View all workouts added to your personal plan.
- Manage daily workout selections.
- Access your saved workouts in one place.

### 4. ⭐ Add to Plan & Save for Later

Each workout comes with two action options:

- **Add to Today's Plan:** Add a workout to your daily workout plan.
- **Save for Later:** Keep your favorite workouts in a separate saved collection.

### 5. 📂 Tab-Based Workout Organization
- Switch between planned workouts and saved workouts using tabs.
- Keep your workout collections organized.
- View your planned and saved items separately.

### 6. 🎨 Empty State UI
- Beautiful "No Data Here" message when the workout plan is empty.
- User-friendly empty states to improve the overall experience.

### 7. 🔢 Dynamic Navbar Counters
- Display the total number of planned workouts.
- Show the total number of saved workouts.
- Keep counts updated as users add or manage workouts.
